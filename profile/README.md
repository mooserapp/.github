<h3 align="center">All your coding agents, in one calm window.</h3>

<p align="center">
  Mooser is a desktop app for working with several coding agents at once: Claude Code, Codex, Gemini CLI, Aider and more.<br>
  Each project is a space, and the sidebar tells you which agent is working, which one needs you and which one is done.
</p>
